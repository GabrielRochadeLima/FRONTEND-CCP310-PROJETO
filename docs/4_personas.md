# Personas

As personas do LeituraJá representam diferentes perfis de leitores, considerando seus hábitos, objetivos, dificuldades e necessidades relacionadas à organização de livros.

O projeto possui duas personas primárias, que representam os principais usuários da plataforma, e uma persona secundária, que representa um perfil com necessidades mais específicas.

As personas são representações fictícias utilizadas para orientar as decisões de interface e usabilidade.

## 1. Persona Primária — Ana Clara

![Foto ilustrativa de Ana Clara](imagens/Ana%20Clara.jpeg)

| Campo | Descrição |
| :--- | :--- |
| **Idade** | 22 anos |
| **Ocupação** | Estudante universitária |
| **Citação** | "Eu salvo vários livros para ler depois, mas, quando quero escolher um, nem lembro mais quais eram." |
| **Objetivos** | Organizar os livros que já leu, está lendo e deseja ler. Acompanhar suas metas e visualizar sua evolução. |
| **Nível de tecnologia** | Alto — utiliza smartphone diariamente e está acostumada com aplicativos e plataformas digitais. |
| **Frustração principal** | Possui muitas recomendações e listas espalhadas, dificultando a organização de sua biblioteca e a escolha da próxima leitura. |

### 1.1 Mapa de Empatia — Ana Clara

| Quadrante | Descrição |
| :--- | :--- |
| **Vê** | Recomendações de livros nas redes sociais, listas salvas no celular, avaliações de outros leitores e diferentes plataformas para descobrir novos títulos. |
| **Ouve** | Amigos recomendando livros, comentários sobre lançamentos e sugestões de leitura compartilhadas por colegas e influenciadores. |
| **Pensa e sente** | Gostaria de manter suas leituras organizadas. Sente satisfação quando conclui um livro, mas fica frustrada quando esquece recomendações ou não consegue decidir o que ler. |
| **Dores** | Recomendações espalhadas, dificuldade para acompanhar as leituras, esquecimento de títulos e indecisão na escolha do próximo livro. |
| **Ganhos** | Biblioteca organizada, histórico de leitura, acompanhamento visual do progresso e facilidade para consultar livros que deseja ler. |

## 2. Persona Primária — Luiz Henrique

![Foto ilustrativa de Luiz Henrique](imagens/Luiz%20Enrique.jpeg)

| Campo | Descrição |
| :--- | :--- |
| **Idade** | 20 anos |
| **Ocupação** | Estudante e estagiário |
| **Citação** | "Eu quero ler mais, mas começo um livro, paro e depois nem lembro quanto tempo fiquei sem ler." |
| **Objetivos** | Criar uma rotina de leitura, estabelecer metas, acompanhar seu progresso e encontrar novos livros para ler. |
| **Nível de tecnologia** | Alto — utiliza smartphone, redes sociais e aplicativos para organizar suas atividades pessoais. |
| **Frustração principal** | Tem dificuldade para manter a frequência de leitura e perde a motivação quando não percebe seu progresso. |

### 2.1 Mapa de Empatia — Luiz Henrique

| Quadrante | Descrição |
| :--- | :--- |
| **Vê** | Pessoas compartilhando metas de leitura, aplicativos de produtividade, desafios literários e conteúdos sobre organização de rotina. |
| **Ouve** | Amigos comentando que terminaram livros, colegas falando sobre falta de tempo e recomendações de criar pequenos hábitos diários. |
| **Pensa e sente** | Gostaria de ler com mais frequência, mas sente dificuldade para conciliar estudos, estágio e atividades pessoais. Fica motivado quando percebe que está avançando. |
| **Dores** | Falta de constância, dificuldade para manter uma rotina, abandono de leituras e pouca percepção do próprio progresso. |
| **Ganhos** | Metas simples, acompanhamento das páginas lidas, visualização do progresso e facilidade para retomar livros em andamento. |

## 3. Persona Secundária — Mariana Oliveira

Mariana representa um perfil complementar de usuário, criado para considerar pessoas que leem ocasionalmente e procuram uma ferramenta simples para organizar seus livros.

| Campo | Descrição |
| :--- | :--- |
| **Idade** | 28 anos |
| **Ocupação** | Assistente administrativa |
| **Citação** | "Gosto de ler no meu tempo livre, mas quero uma forma simples de lembrar quais livros já terminei." |
| **Objetivos** | Registrar livros concluídos, manter uma lista de futuras leituras e consultar sua biblioteca quando necessário. |
| **Nível de tecnologia** | Intermediário — utiliza aplicativos no dia a dia, mas prefere interfaces simples e com poucas etapas. |
| **Frustração principal** | Não gosta de aplicativos com muitas opções ou processos demorados para registrar informações básicas. |

### 3.1 Mapa de Empatia — Mariana Oliveira

| Quadrante | Descrição |
| :--- | :--- |
| **Vê** | Livros em livrarias, recomendações de amigos, listas de títulos populares e aplicativos com diferentes formas de organizar leituras. |
| **Ouve** | Amigos indicando livros, familiares comentando sobre histórias que leram e sugestões de títulos para momentos de descanso. |
| **Pensa e sente** | Considera a leitura uma atividade de lazer. Quer organizar seus livros sem precisar utilizar um aplicativo complexo. |
| **Dores** | Dificuldade para lembrar livros já lidos, pouco tempo para organizar listas e interfaces com funcionalidades desnecessárias. |
| **Ganhos** | Cadastro rápido de livros, biblioteca fácil de consultar, categorias claras e navegação simples. |

## 4. Considerações Finais

As três personas representam necessidades diferentes que devem ser consideradas no desenvolvimento do LeituraJá.

**Ana Clara** busca organizar recomendações e manter o controle de sua biblioteca. **Luiz Henrique** precisa acompanhar seu progresso e manter a motivação para ler. **Mariana Oliveira** procura uma solução simples para registrar suas leituras sem dificuldades.

Esses perfis ajudam a definir as principais funcionalidades do sistema, como organização da biblioteca, atualização do progresso, acompanhamento de metas e navegação intuitiva.
