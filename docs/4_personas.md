# Personas

## Exemplo de entrega

> Continuação do exemplo fictício do app "Estuda+", usando o segmento "Participante" priorizado no [Perfil do Usuário](3_perfil_usuario.md). Copie a estrutura, não o conteúdo.

### Persona primária: Ana Clara

![foto de rosto ilustrativa](imagens/Ana%20Clara.jpeg)


| Campo | Descrição |
| :---- | :---- |
| **Idade** | 22 anos |
| **Ocupação** | Estudante Universitária |
| **Citação** | "Eu salvo vários livros para ler depois, mas quando quero escolher um, nem lembro mais quais eram." |
| **Objetivos** | Organizar os livros que já leu, os que está lendo e os que deseja ler; acompanhar suas metas e visualizar sua evolução. |
| **Nível de tecnologia** | Alto — utiliza smartphone diariamente e está acostumada com aplicativos e plataformas digitais. |
| **Frustração principal** | Possui muitas recomendações e listas espalhadas, dificultando acompanhar sua biblioteca e decidir qual livro ler em seguida. |

### Mapa de Empatia — Ana Clara

| Quadrante | Descrição |
| :---- | :---- |
| **Vê** |Listas de livros salvas no celular, recomendações nas redes sociais, estantes cheias de livros e aplicativos/sites diferentes para descobrir novos títulos. |
| **Ouve** |Amigos recomendando livros, pessoas comentando sobre lançamentos e colegas dizendo "Salva livros que pretende ler, começa novas leituras, procura avaliações e recomendações, mas nem sempre registra o que já leu ou mantém sua lista organizada. |
| **Pensa e sente** | Gostaria de ter mais controle sobre suas leituras; sente satisfação quando termina um livro e acompanha seu progresso, mas fica frustrada quando não consegue encontrar ou lembrar das recomendações que salvou. |
| **Dores** | Livros e recomendações espalhados em diferentes lugares; dificuldade para acompanhar o progresso; esquecimento de livros que gostaria de ler; dificuldade para escolher a próxima leitura. |
| **Ganhos** | Biblioteca organizada, acompanhamento visual do progresso, metas de leitura, histórico de livros e recomendações que facilitem a escolha da próxima leitura. |

### Persona primária: Luiz Henrique

![foto de rosto ilustrativa](imagens/Luiz%20Enrique.jpeg)


| Campo | Descrição |
| :---- | :---- |
| **Idade** | 20 anos |
| **Ocupação** | Estudante e estagiario |
| **Citação** | "Eu quero ler mais, mas começo um livro, paro e depois nem lembro quanto tempo fiquei sem ler." |
| **Objetivos** | Criar uma rotina de leitura, estabelecer metas, acompanhar seu progresso e encontrar facilmente novos livros para ler. |
| **Nível de tecnologia** | Alto — usa smartphone diariamente, redes sociais e aplicativos para organizar atividades pessoais. |
| **Frustração principal** | Tem dificuldade em manter constância na leitura e escolher o próximo livro, perdendo a motivação quando não percebe seu progresso. |

### Mapa de Empatia — Luiz Henrique

| Quadrante | Descrição |
| :---- | :---- |
| **Vê** |Listas de livros salvas no celular, recomendações nas redes sociais, estantes cheias de livros e aplicativos/sites diferentes para descobrir novos títulos. |
| **Ouve** |Amigos recomendando livros, pessoas comentando sobre lançamentos e colegas dizendo "Salva livros que pretende ler, começa novas leituras, procura avaliações e recomendações, mas nem sempre registra o que já leu ou mantém sua lista organizada. |
| **Pensa e sente** | Gostaria de conseguir ler com mais frequência; sente satisfação quando consegue cumprir uma meta, mas pode se frustrar quando passa muito tempo sem ler ou abandona uma leitura. |
| **Dores** |Falta de constância, dificuldade para criar uma rotina, excesso de livros salvos, dificuldade para escolher a próxima leitura e pouca percepção do próprio progresso. |
| **Ganhos** | Metas simples, progresso visual, lembretes opcionais, recomendações personalizadas e uma forma rápida de descobrir o próximo livro. |
