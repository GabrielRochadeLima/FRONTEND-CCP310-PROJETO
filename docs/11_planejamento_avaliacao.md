# Planejamento da Avaliação

## 1. Planejamento de Usabilidade (Método DECIDE)

A avaliação busca verificar se a plataforma é simples de usar e se suas funcionalidades atendem às necessidades dos usuários.

| Etapa | Descrição |
| :---: | :--- |
| **D** | **Determinar objetivos:** avaliar a navegação e a facilidade de uso. |
| **E** | **Explorar questões:** verificar se o usuário consegue cadastrar livros, organizar leituras, atualizar o progresso e consultar metas. |
| **C** | **Escolher métodos:** utilizar questionários, observação e avaliação heurística. |
| **I** | **Identificar questões práticas:** realizar testes com colegas e leitores, utilizando o protótipo. |
| **D** | **Decidir questões éticas:** solicitar consentimento e preservar os dados dos participantes. |
| **E** | **Examinar resultados:** identificar dificuldades e possíveis melhorias na interface. |

## 2. Lista de Instrumentos

### 2.1 Termo de Consentimento

Documento para autorizar a participação voluntária nos testes, com uso dos dados apenas para fins acadêmicos.

### 2.2 Questionário

1. A plataforma é fácil de utilizar?
2. As funcionalidades são fáceis de encontrar?
3. A organização dos livros está clara?
4. Encontrou alguma dificuldade?
5. O que poderia melhorar?
