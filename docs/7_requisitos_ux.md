# Requisitos de UX e Metas de Usabilidade

## 1. Características da Plataforma

| Característica | Descrição |
| :---- | :---- |
| Descrição do Software | Plataforma web para organizar livros, acompanhar o progresso de leitura e consultar metas pessoais. O objetivo é oferecer uma interface simples e fácil de utilizar. |
| Descrição do Hardware | A plataforma poderá ser acessada por computadores, notebooks, tablets e smartphones com conexão à internet e navegador atualizado. |
| Capacidades da Plataforma | **1. Cadastro de livros:** adicionar livros à biblioteca pessoal. **2. Organização:** separar livros entre quero ler, lendo e lido. **3. Progresso:** registrar páginas lidas. **4. Metas:** definir e acompanhar objetivos de leitura. **5. Pesquisa:** localizar livros pelo título. |
| Restrições da Plataforma | **1. Internet:** necessária para acessar a plataforma. **2. Navegador:** algumas funcionalidades podem apresentar diferenças em navegadores desatualizados. **3. Dispositivos:** a interface precisa se adaptar a diferentes tamanhos de tela. **4. Dados:** as informações pessoais devem ser armazenadas com segurança. |

## 3. Metas de Usabilidade

### 3.1 Qualitativo

As principais metas qualitativas do projeto são:

1. **Facilidade de aprendizado:** permitir que novos usuários compreendam rapidamente como utilizar a plataforma.
2. **Organização:** apresentar os livros e suas informações de maneira clara.
3. **Eficiência:** reduzir a quantidade de etapas necessárias para cadastrar livros e atualizar leituras.
4. **Satisfação:** oferecer uma experiência agradável, sem excesso de informações na tela.
5. **Acessibilidade:** utilizar textos legíveis, contraste adequado e elementos de navegação compreensíveis.
6. **Prevenção de erros:** apresentar mensagens claras e permitir a correção de informações cadastradas.

### 3.2 Quantitativo

As metas abaixo representam os critérios que pretendemos avaliar durante os testes de usabilidade.

| Metas | Porcentagem | Justificativa |
| :---- | :---- | :---- |
| Facilidade de aprendizado | 25% | O usuário deve conseguir entender as principais funcionalidades sem precisar de muitas instruções. |
| Eficiência na realização das tarefas | 25% | O cadastro de livros e a atualização do progresso devem ser rápidos e simples. |
| Facilidade de navegação | 20% | As principais funcionalidades devem ser encontradas sem dificuldade. |
| Satisfação do usuário | 20% | A experiência deve ser agradável e atender às necessidades identificadas na pesquisa. |
| Prevenção e recuperação de erros | 10% | A interface deve evitar erros e facilitar sua correção. |
| **Total** | **100%** | |

As porcentagens representam o peso de cada critério na avaliação de usabilidade, e não resultados já obtidos.

Durante os testes, poderemos avaliar o desempenho dos participantes nas tarefas de cadastrar livros, organizar a biblioteca, atualizar o progresso e consultar metas.

## Considerações finais

Os requisitos e as metas apresentados foram definidos considerando as dificuldades identificadas na pesquisa com usuários e as funcionalidades propostas na análise de tarefas.

O principal objetivo é desenvolver uma plataforma simples, organizada e acessível, que facilite o acompanhamento das leituras sem exigir muitas etapas ou conhecimentos técnicos.
