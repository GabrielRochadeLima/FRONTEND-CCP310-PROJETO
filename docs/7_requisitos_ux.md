# Requisitos de UX e Metas de Usabilidade

## 1. Características da Plataforma

| Característica | Descrição |
| :--- | :--- |
| Descrição do Software | Plataforma web para organizar livros, registrar leituras e acompanhar metas pessoais. |
| Descrição do Hardware | Acesso por computadores, tablets e celulares com navegador e internet. |
| Capacidades da Plataforma | **1. Cadastro:** adicionar livros. **2. Organização:** classificar como quero ler, lendo ou lido. **3. Progresso:** registrar páginas lidas. **4. Metas:** criar e acompanhar objetivos. **5. Pesquisa:** buscar livros pelo título. |
| Restrições da Plataforma | **1. Internet:** necessária para o acesso. **2. Navegador:** precisa ser atualizado. **3. Dispositivos:** a interface deve se adaptar a diferentes telas. **4. Segurança:** os dados dos usuários devem ser protegidos. |

## 3. Metas de Usabilidade

### 3.1 Qualitativo

As metas qualitativas são:

1. **Aprendizado:** facilitar o uso para novos usuários.
2. **Organização:** apresentar os livros de forma clara.
3. **Eficiência:** permitir realizar tarefas com poucas etapas.
4. **Satisfação:** manter uma interface simples e agradável.
5. **Acessibilidade:** garantir boa leitura e navegação.
6. **Prevenção de erros:** mostrar mensagens claras e permitir correções.

### 3.2 Quantitativo

Os critérios abaixo serão utilizados como referência nos testes de usabilidade.

| Metas | Porcentagem | Justificativa |
| :--- | :--- | :--- |
| Facilidade de aprendizado | 25% | Entender as funções sem muitas instruções. |
| Eficiência nas tarefas | 25% | Cadastrar livros e atualizar leituras rapidamente. |
| Facilidade de navegação | 20% | Encontrar as funções sem dificuldade. |
| Satisfação do usuário | 20% | Oferecer uma experiência agradável. |
| Prevenção e correção de erros | 10% | Evitar erros e facilitar correções. |
| **Total** | **100%** | |

As porcentagens representam o peso de cada critério, não resultados dos testes.

## Considerações finais

Os requisitos foram definidos com base na pesquisa com usuários e na análise de tarefas. A proposta é criar uma plataforma simples, acessível e prática para organizar e acompanhar leituras.
