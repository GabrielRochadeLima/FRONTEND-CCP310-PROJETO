# 📚 Plataforma de Registro de Obras Literárias

Sistema desenvolvido para ajudar leitores a organizar e acompanhar suas leituras.

## 📖 Sobre o projeto

A Plataforma de Registro de Obras Literárias permite que usuários cadastrem livros, acompanhem seu progresso de leitura, definam metas e recebam recomendações de obras.

O projeto tem como objetivo facilitar a organização das leituras e incentivar o hábito de ler.

## 🎯 Objetivos

- Registrar livros lidos;
- Acompanhar o progresso das leituras;
- Organizar livros por status;
- Criar metas de leitura;
- Oferecer recomendações de livros;
- Permitir que o usuário acompanhe seu histórico de leitura.

## 👤 Usuário final

O sistema é destinado principalmente a leitores que desejam organizar suas leituras e acompanhar seu progresso.
